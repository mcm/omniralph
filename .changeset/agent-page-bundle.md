The agent page opens in the browser: `omniralph-agent ui` now serves the Omniralph design, with the agent's name and control panel in the top bar and its sections (Overview, Logs, Capacity, Packages, Host tools, Version, Claude, Storage) in a nav that marks a problem with a dot. The page keeps itself current over the agent's live stream, polls while the stream is down, and asks to be opened again after the agent restarts.
