## Design Specificity Verdict

**LLM assessment:** authored for this product, not generic. The Flight Recorder idea shows: mono timestamps in a fixed column, badges with code-host and tracker marks, one progress card reused on Inbox, Runs and Fleet, lavender kept rare. The staged save card with its consequence line and the typed revoke are product-specific. It falls back to generic in the empty right panes of Backlog and Fleet, the Analytics card grid, the Ask new-chat page and the settings sub-nav.

**Deterministic scan:** the source trees are clean (0 findings, exit 0 on all three). The rendered snapshots are not. The root layout still imports `@iamthemcmaster/ui/styles` (`apps/web/src/app/layout.tsx:2-3`), and `LegacyFrame` (`apps/web/src/app/(app)/legacy-frame.tsx`) still wraps every page in 1.x `TooltipProvider` and the 1.x `UnsavedChangesBar`. So every panel page ships the 1.x Precision Aurora CSS: the whiteout sheen marquee, the aurora radial halos and the `.unsaved-bar`. No element renders the marquee or the halos today, but the bar does render ("1 card has unsaved changes: Reviews", `repo-reviews-unsaved.desktop.dark.png`). `error.tsx` is still built from 1.x components. The detector agrees with A's observation of a leftover second unsaved-changes surface on Repos. False positives (fixed-height chips, padded table wraps, the devtools logo, the light page token) are recorded in ignore.md.

**Visual overlays:** none. There is no browser automation on the host.

## Overall Impression

A disciplined, product-specific system whose screens mostly hold up at all three widths and both themes. The biggest problems are trust and finishability: status lines that disagree with the data under them, Inbox items whose real decision is missing, epic step transcripts and diffs that never load, and an Ask panel a keyboard can't reach. The largest single opportunity is to make every status line come from one source of truth for "which step is running".

## What's Working

1. **The staged save card.** It shows before → after and the consequence before saving ("PR opened On → Off · Opening a pull request won't start a review", `repo-reviews-unsaved.*`).
2. **Consistent badge language.** References carry their host or tracker mark on every surface and theme, and light is a full theme, not an inversion.
3. **Calm, disciplined color.** Coral and lavender stay rare, so the Problems tab, the Fleet dot and "Waiting on you" really do stand out.

## Priority Issues

- **[P1] The PRD-ready and PR-waiting Inbox items can't be acted on.**
  - What: they offer only `Done` and `Snooze` (`apps/web/src/components/runs/decisions.ts:22-23`; `inbox-prd-ready.phone.light.png`, `inbox-pull-request.desktop.light.png`).
  - Why: the decision the item exists for is missing, and "Done" reads as "I did it".
  - Fix: for `prd_ready`, make the existing "Start epic" (`START_EPIC`, `useStartWorkItem`) the lavender clearing button. For `pr_waiting`, add a labeled "Open pull request" / "Open merge request".
  - Serves: rule 6. Suggested: /impeccable clarify.
- **[P1] Status lines contradict their own data.**
  - What: "story 4 of 9" while story 3 runs; "Queued" over "1 running" with a full mint bar; "Running for 19 minutes" over "Waiting for an agent."; a triage turn's full bar at "0 of 1 done"; "Failed 0" beside a failed delivery.
  - Evidence: `run-epic-running.*`, `runs.desktop.dark.png`, `inbox-running.rail.light.png`, `settings-connection-github.*`.
  - Fix: derive "story N" from the running step's position, and each label and count from the same state.
  - Serves: H1, the State Vocabulary Rule. Suggested: /impeccable harden.
- **[P1] Epic step transcripts and story diffs never load.**
  - What: every capture of a step's Transcript and Diff gets a 404 from `/api/ui/runs/[id]/attempts/[attemptId]/transcript` or `…/steps/[stepId]/diff`.
  - Evidence: run-epic-step, run-epic-step-panel, run-epic-diff, run-epic-failed; `consoleErrors` in results.json.
  - Why: the seed has transcripts and a fixture diff (`seed.test.ts` reads them through the read paths), so the HTTP path or the IDs it gets are wrong.
  - Serves: rule 20, H1, H9. Suggested: /impeccable harden.
- **[P1] The Ask panel is unreachable by keyboard.**
  - What: Tab never reaches the chat links, "Show more", "New chat" or "Close Ask" in the panel over Runs (`ask-panel.desktop.dark`, keyboard walk).
  - Serves: WCAG 2.1.1. Suggested: /impeccable harden.
- **[P1] Layout breaks at the 1024 px rail.**
  - What: on Members, the invitation row squeezes the Emails input to about 75 px (`settings-members.rail.light.png`); with an agent open, Fleet's "Pinned repos" column is cut with no ellipsis (`fleet-agent.rail.light.png`); the Runs filters wrap (`run-epic-step-panel.rail.dark.png`).
  - Serves: DESIGN.md widths, WCAG 1.4.10. Suggested: /impeccable adapt.
