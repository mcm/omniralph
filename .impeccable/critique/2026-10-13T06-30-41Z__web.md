## What's Working

1. **Failure reasons are first-class.** `ListErrorRow` gives the reason its own full-width line, clamped to 2 lines, with a keyboard-reachable "Show all", in both themes and on phone.
2. **Exact values are handled with care.** `monoValueTail` keeps `/control-panel#300`, `MonoPath` H1s break only after `/`, and dates drop the current year.
3. **Confirmations are true diffs.** Prompts and descriptions show as −/+ lines in a capped, scrollable diff.

## Priority Issues

**[P2-A] Analytics "Dismissal rate per repository" pushes the Rate off-screen at 390px** (regression in changed code, from the round-3 P3-3 fix)
- **What:** the repository path is now a nowrap `MonoValue` in an auto-width cell. At 390 the Rate column (bar and %) sits past the card's right edge, behind a right-edge fade and an in-card horizontal scroll, and the % values are not visible. Round 3 showed 32% / 25% / 17% / 13% there.
- **Why it matters:** the rate is the only reason this table exists, and phone must work without horizontal scroll.
- **Evidence:** `analytics.phone.dark.png` (Dismissal card, `data-overflow-end="true"` in `analytics.phone.dark.html`) vs round 3's `.screens/2026-10-13T04-51-32-666Z/analytics.phone.dark.png`. Code: `analytics-view.tsx:99`, `globals.css` `.analytics-repo-link`. The cell has no width constraint, so `MonoValue`'s `max-width: 100%` never truncates.
- **Fix:** below 768px, give the Repository cell `width: 100%; max-width: 0` (the `.jobs-col-target` pattern) so `MonoValue` middle-truncates, or use `MonoPath` so it wraps after `/`.
- **Suggested command:** /impeccable adapt

**[P2-B] In dark theme, the `strong` medium chip is the brightest severity** (changed code; partial regression of round-2 P2-1)
- **What:** in dark, "Medium" has primary-white text and a `--border-strong` outline. It has more contrast than the red-tinted Critical and amber High beside it. In light it reads like a selected toggle.
- **Why it matters:** the eye goes to medium first, which inverts the severity scan the ramp exists for. TOOL-454 says "critical is visually strongest, then high, medium…".
- **Evidence:** `reviews.desktop.dark.png` (#300 and #307 Findings), `analytics.phone.dark.png` (Findings by severity), `review.phone.dark.png`. Code: `state-variants.ts:102`, `globals.css:951-955`, `review-badges.tsx:25-29`.
- **Fix:** step medium down so it is quieter than high and louder than low in both themes, for example secondary-level text with a border one step above low. Add a check, a test or a measured note, that critical > high > medium > low > info by perceived prominence in both themes.
- **Suggested command:** /impeccable colorize

**[P2-C] Reviews list: failure reason truncated and hover-only, and severity counts wrap to 3 lines** (reason newly noticed in unchanged code; the wrap is a regression in changed code that breaks a TOOL-454 criterion)
- **What:**
  - A failed review's reason reads "The harness lost it…", with the full text only in `title`.
  - Row #300's severity words wrap to three lines in the fixed 9.5rem Findings column, and four more rows wrap to two.
  - PR titles are cut to about 20 characters, and repository paths truncate at the end ("fixture-labs/legacy-dashbo…") instead of the middle.
- **Why it matters:** this is the same "why did it fail" fact that round 3's P2-A fixed on Jobs and Ralph. Reviews is now the one list that hides it from keyboard and touch, and its rows are no longer one line plus one meta line.
- **Evidence:** `reviews.desktop.light.png`, `reviews.desktop.dark.png` (#335 and #345 reasons; #300 Findings). Code: `reviews-view.tsx:121-123`, `globals.css:897-923` (`.review-error`, `.review-ellipsis`) and `.review-col-findings`.
- **Fix:**
  - Use `ListErrorRow` for failed reviews, as Jobs and Ralph do.
  - Keep the severity counts on one line at 1440, either by budgeting the column (measure it, as TOOL-462 did for Jobs) or by showing words only where they fit.
  - Give the title more width, and render the repository through `MonoValue` so it middle-truncates.
- **Suggested command:** /impeccable layout
