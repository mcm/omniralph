## Minor Observations (P3)

1. The stopped-run header says "stopped" twice: "The run was stopped. Stopped by Ada Admin." (`apps/web/src/lib/runs/reason.ts:106` plus the error line; `inbox-stopped-epic.*.aria.yml`). Make it one sentence ("Ada Admin stopped the run."). Rule 4.
2. On phone Analytics, the 2-column stat grid has 5 tiles, so "Tokens out" sits alone next to an empty half cell (`analytics.phone.light`; `packages/ui/styles/surfaces.css:652-669`). Let an odd last cell span both columns.
3. The agent Version page's Update tile still says "Pinned to 2.3.1" next to the Running 2.3.1 badge (`apps/agent/ui/src/pages/version/model.ts:46`; `agent-version.desktop.light`), while Overview now says "Pinned". Make the two pages agree.
4. Mono reference badges are 11.5px (`packages/ui/styles/refs.css:47`, `.or-ref__text.or-mono`), below DESIGN.md's 12px floor. It isn't a recorded exception, and it shows on 73 of 115 routes (issue IDs, SHAs). Inline `code` in 13px markdown contexts (`content.css:102`, `0.9em` inside tables and h4–h6) computes to about 11.7px.
5. The command palette sets agent names in sans (`apps/web/src/components/search/search-palette.tsx:177`), but Fleet and the agent header set them in mono (`agent-panel.tsx:245`). Rule 21: same thing, same treatment.
6. The nav's hover and current-page backgrounds are close: hover vs current about 1.04:1 in light, current vs sidebar 1.12 / 1.06 (`packages/ui/styles/shell.css:160-168`). The current item also changes text from secondary to primary, and the page h1 names the page, so you can still tell where you are. A stronger neutral current-page mark (weight, or a neutral bar, not lavender per rule 15) would make it read at a glance.
7. "Fixture Labs's" in the Leave line (`apps/web/src/screens/settings/general-settings.tsx:44`). "this organization's" avoids awkward possessives.
8. At rail width the Fleet Health tile wraps "6 / offline" (`fleet.rail.light`). Join the count and its word with a no-break space.
9. The shared review page repeats its title: the h1 "Export runs as CSV", then the PRD's own "PRD: Export runs as CSV" (`share-review.phone.light`).

Non-goal notes, not filed: no batch triage, no pin-menu filter, no capacity-pool sum check, no plain-language descriptions for the playbook editor's tool IDs.
